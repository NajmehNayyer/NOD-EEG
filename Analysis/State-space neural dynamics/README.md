# State-Space Neural Dynamics

## Overview
Computational workflows for mapping time-resolved state-space neural dynamics across EEG recordings, evaluating population trajectories in both **trial-averaged** and **single-trial** responses.

## Key Focus Areas
* **Trial-Averaged Dynamics**: Analyzing population-level state-space trajectories across averaged conditions.
* **Single-Trial Dynamics**: Mapping trial-to-trial variability and temporal trajectory evolution in high-dimensional neural data.
